## 📖 About This Project

This is the **second project** in my React learning series! I built this Counter App to practice **state updates** and **event-driven UI changes** in React.

> 💡 **Perfect for beginners** — this project shows how a single piece of state (`num`) can drive multiple parts of the UI at once, and how different functions can update that state in different ways.

---

## 🎯 What You'll Learn

Exploring this project's code will help you understand:

| Concept | Description |
|---|---|
| 🔄 **State Management** | Using the `useState` hook to store and update a numeric value |
| ➕➖ **State Updates** | Incrementing, decrementing, and resetting state with separate handler functions |
| 🖱️ **Event Handling** | Wiring up `onClick` events to trigger state changes |
| 🔁 **Reactive Rendering** | Seeing how one state value automatically updates multiple elements on re-render |

## 💻 Run Locally

Want to test and experiment with this project on your own machine? Follow these steps:

**1. Navigate to this folder**
```bash
cd 02-Counter-App
```

**2. Install dependencies**
```bash
npm install
```

**3. Start the development server**
```bash
npm run dev
```

**4. Open in your browser**
```
http://localhost:5173
```
